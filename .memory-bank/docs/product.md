# Product Overview

## Что это

Веб-справочник «Рецепты» для домашней аудитории: 290 блюд со ссылками на
первоисточник (ivlevchefbooks.ru), который делает поиск и просмотр рецептов
быстрыми на любом устройстве.

## Для кого

- Домашний пользователь: быстро найти идею блюда и перейти к полному рецепту
- Владелец коллекции: пополнять справочник одной строкой в CSV без правок кода

## Ключевые сценарии (top-3..5)

1. Открыть сайт → пролистать/отфильтровать по категории → перейти к рецепту
   на ivlevchefbooks.ru (новая вкладка)
2. Найти блюдо поиском по названию (регистр и ё/е не важны), комбинируя с категорией
3. Добавить рецепт: строка в `receps.csv` → `npm run build:data` → commit → push,
   сайт обновляется автоматически

## Принципы продукта

- Минимализм: без сборки, без зависимостей, без сервера — чистая статика
- CSV — единственный источник правды по данным; JSON — производный артефакт
- Ссылки на рецепты ведут на первоисточник, контент не дублируется

## Что это НЕ (границы)

- Не кулинарная база с полными текстами рецептов — только навигация по ссылкам
- Без пользователей, аккаунтов, комментариев и персонализации
- Без оффлайна и PWA (пока не требуется)
