# Шаблон: файл шага (YY-<имя-шага>.md)

> Один файл на шаг. Агент выполняет шаг, читая ТОЛЬКО этот файл + Workflow-цикл из plan.md.

```markdown
# Шаг YY: {Название шага}

## Briefing
- **Цель:** {коротко и ёмко, чего достигаем этим шагом}
- **Ключевые файлы:**
  - `src/.../service.ts` (создать / изменить / только прочитать)
  - `src/.../service.test.ts` (создать)
- **Additional info:** {тонкости, на что обратить внимание, детали реализации,
  подводные камни, ссылки на Reference Materials из plan.md}

## Sub-tasks
{Детальный пошаговый план. Пути — от корня проекта. До 5–7 задач.}

1. **{Действие}:** {что именно сделать, как, какие особенности}
2. **{Действие}:** {…}
3. **Тесты:** создать `...test.ts`, покрыть {что именно}: успех, ошибка, граничные случаи.
4. **Документация:** {если шаг меняет документированное поведение — какой файл MBB обновить}

## Acceptance criteria (шаг считается готовым, когда)
- {проверяемое условие 1}
- {проверяемое условие 2}
- Проверки из `.flow/gates.md` зелёные.
```
