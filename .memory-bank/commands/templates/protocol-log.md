# Шаблон: log.md (журнал работы)

> Append-only: записи только добавляются, старые не переписываются и не удаляются.
> Пишем не «дубль git log», а суть: особенности реализации, решённые проблемы, неочевидные детали.

```markdown
# Work Log: NNNN — {краткое имя}

Записи только добавляются. Формат каждой записи:

---
### Шаг {YY} — {дата}
- **Сделано:** {что именно}
- **Почему так:** {обоснование неочевидных решений}
- **Проблемы и решения:** {с чем столкнулся, как разрулил}
- **Commit:** {hash}
```
