# ⚡ Performance patterns (уроки проекта)

> Записи с confidence ≥ 0.9 агент применяет автоматически при проектировании; 0.7–0.9 —
> рассматривает и обосновывает; ниже — только как идею для проверки.

Формат записи:

```markdown
### [PP-NN] Краткое название паттерна
- **Контекст:** где применим
- **Паттерн:** что делать
- **Эффект:** измеримый результат (числа, до/после)
- **Источник:** протокол NNNN, коммит abc1234
- **Confidence:** 0.0–1.0
- **Статус:** candidate → proven
```

### [PP-01] Пример-шаблон (замените реальными записями)
- **Контекст:** пример
- **Паттерн:** пример
- **Эффект:** пример
- **Источник:** —
- **Confidence:** 0.0
- **Статус:** candidate
