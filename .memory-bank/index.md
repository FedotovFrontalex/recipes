# 🧠 Memory Bank — карта знаний проекта

> **Агенту:** это точка входа сессии. Прочитай файл полностью, затем открой разделы,
> релевантные текущей теме. Аннотации под каждой ссылкой говорят, зачем её открывать.

Проект ведётся по принципам MBB: единый источник правды (SSOT), атомарные duo-файлы,
индексные файлы с аннотированными ссылками, иерархия C4 (L1 система → L2 контейнеры → L3 компоненты).

## 📋 Протоколы (единицы работы)

- `.protocols/` — папки `NNNN-имя/` с планом (ADR), шагами `YY-имя.md`, `log.md` и `context.md`.
- Номер NNNN идентифицирует протокол; промпт вида «прочитай протокол 0042 из .protocols/» работает.
- Протоколы ведутся по командам из `commands/` (канон) — см. [FlowForge: команды](commands/flow-help.md).
- Конфиг проверок шагов: `.flow/gates.md`. Шаблоны артефактов: `.flow/templates/`.
