# 📜 Memory Bank Bible (MBB)

Стандарты ведения документации проекта. Любой новый документ в `.memory-bank/` должен соответствовать этим правилам.

## Состав

- [Principles](principles.md) — основополагающие принципы: SSOT, атомарность, C4, иерархия информации, качество текста.
- [File standards](file-standards.md) — frontmatter, duo-файлы, аннотированные ссылки, именование, tier-система размеров.

## Быстрая шпаргалка (когда некогда читать принципы)

1. Один файл = одна концепция. Если файл > 800 строк — декомпозируй.
2. Каждая концепция живёт в одном месте (SSOT) — нигде не дублируй, только ссылайся.
3. У каждого файла — frontmatter (см. [file-standards](file-standards.md)).
4. Саммари-файл: 150–250 строк, тезисы + аннотированные ссылки на детали.
5. Место в структуре определяй по C4: система (docs/ корень) → контейнер (docs/<container>/) → компонент (docs/<container>/<component>/).
6. Новые файлы обязательно включай в ближайший index.md, иначе они «сироты».
