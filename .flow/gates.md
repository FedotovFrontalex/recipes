# Quality Gates — команды проверок проекта

> Заполняется один раз при инициализации (или агентом по запросу «заполни gates.md по проекту»).
> Используется всеми командами протоколов: эти проверки обязательны после каждого шага.
> Агент запускает их из корня worktree (или main для flow-mini). TODO обязателен к заполнению.

## Обязательные проверки (после каждого шага)

```yaml
typecheck: node --check js/app.js && node --check scripts/build-data.mjs && node --check scripts/validate-data.mjs
lint:      N/A   # линтер не настроен: vanilla JS без зависимостей; включить при появлении тулинга
test:      node scripts/validate-data.mjs   # валидация данных рецептов (структура, ссылки, дубли)
```

> Примечание: команды typecheck/test активны с шага 01 протокола 0001 (когда появятся файлы).
> До этого для пустой базы — N/A.

## Полная верификация (только на шаге 2-m команды flow-review)

```yaml
build: node scripts/build-data.mjs   # регенерация data/recipes.json из receps.csv
```

## Опциональные проверки (если настроены)

```yaml
e2e:      N/A    # браузерные e2e не настроены
coverage: N/A    # покрытие не считаем: UI без сборки и зависимостей
```

## Правила

- Проверки запускаются после КАЖДОГО шага протокола; шаг не считается завершённым,
  пока все обязательные проверки не зелёные.
- Если проверка упала — исправляй до зелёного; нельзя коммитить красное.
- Если `lint` после шагов стабильно выдаёт много ошибок — значит агенты систематически
  нарушают стиль проекта: исправь не код, а соглашения в `.memory-bank/docs/structure.md`.
- Меняешь команды проверок (новый инструмент) — обнови этот файл в рамках протокола.
