# FlowForge — агентная разработка проекта

## Прайминг контекста (каждая новая сессия)

В начале каждой рабочей сессии: **прочитай файл `.memory-bank/index.md` полностью** — это карта знаний проекта. Затем прочитай разделы, релевантные теме сессии (файл-индекс каждого раздела подскажет, куда идти). Только после этого принимай задачу.

## Что это за фреймворк

FlowForge объединяет два подхода:

1. **Memory Bank** (`.memory-bank/`) — база знаний проекта прямо в репозитории: аннотированные индексы, C4-структура, единый источник правды. Правила ведения — в `.memory-bank/mbb/`.
2. **Protocol** (`.protocols/`) — единица работы: пронумерованные папки `NNNN-имя/` с планом (ADR), шагами, логом и состоянием. Каждый протокол = ветка + worktree + Draft PR.
3. **Quality Gates** (`.flow/gates.md`) — команды проверок (typecheck/lint/test/build), обязательные после каждого шага протокола.

## Команды (в ZCode: слэш-команды, канон в .memory-bank/commands/)

| Команда | Когда использовать |
|---|---|
| `/flow-new "имя"` | Зафиксировать обсуждённый план доработки в протокол (worktree + Draft PR) |
| `/flow-resume NNNN` | Восстановить прерванную работу по протоколу |
| `/flow-review NNNN` | Ревью, гейты качества, merge в main, чистка, запись уроков |
| `/flow-mini "имя"` | Небольшая доработка (до ~2 часов) — протокол прямо на main |
| `/flow-help` | Карта фреймворка и выбор команды |

Задачи до ~30 минут можно делать без протокола: прогретый контекст → анализ → фикс.

## Дисциплина (обязательно)

- Вся работа по протоколу ведётся **из папки worktree**, никогда из основного репозитория. Проверяй CWD и текущую ветку перед каждой записью файлов.
- Файлы плана (`plan.md`, `NN-*.md`) — **контракт**, их нельзя менять в ходе реализации.
- Каждый коммит шага несёт тег `[protocol-NNNN/YY]`; перед коммитом — проверки из `.flow/gates.md` должны пройти.
- Ветка `main` должна оставаться чистой: периодически проверяй, что файлы из worktree случайно не попали на main.
- `log.md` — только добавление записей, никогда не переписывать старые.
- Документацию обновляй по правилам MBB (`.memory-bank/mbb/principles.md`): SSOT, атомарные duo-файлы, C4.
- Не выдумывай пути: сначала смотри индексы в `.memory-bank/`, затем код.
