# Шаг 02: UI — каркас и карточки

## Briefing
- **Цель:** страница отображает все рецепты карточками; адаптивная сетка; рецепт
  открывается в новой вкладке.
- **Ключевые файлы:**
  - `index.html` (создать: семантический каркас, meta viewport, `main` с сеткой)
  - `css/styles.css` (создать: mobile-first, CSS-переменные, адаптивная сетка)
  - `js/app.js` (создать: загрузка JSON, рендер карточек, состояние ошибки)
- **Additional info:**
  - **Все пути относительные** (`./css/styles.css`, `./data/recipes.json`,
    `./js/app.js`) — сайт будет жить в подпути `/recipes/` на Pages. Никаких
    ведущих слэшей.
  - `js/app.js` подключать с `defer`. Данные грузить `fetch('./data/recipes.json')`
    — значит локально нужен http-сервер (file:// не сработает): `npx --yes serve .`.
  - Сетка: CSS Grid `repeat(auto-fill, minmax(230px, 1fr))` с gap; на узких экранах
    вырождается в 1 колонку естественно; проверить 375 / 768 / 1280 px.
  - Карточка: `<article>` — название, бейдж категории, ссылка «Открыть рецепт»
    (`target="_blank" rel="noopener"`), вся карточка кликабельна (ссылка-обёртка).
  - Доступность: контрастные цвета, `:focus-visible`, тач-таргеты ≥ 44px, шрифт
    системный стек, `<html lang="ru">`.
  - Счётчик «Всего рецептов: N» с `aria-live="polite"` — пригодится для шага 3.

## Sub-tasks
1. **index.html:** header (заголовок «Рецепты», подзаголовок), секция счётчика,
   `main#grid`, `noscript` с предупреждением, footer (источник данных).
2. **css/styles.css:** переменные (цвета, радиусы, тени), мягкий reset, сетка,
   карточка с hover-состоянием (поднятие/тень), бейдж категории.
3. **js/app.js:** JSDoc-функции `loadRecipes()`, `renderCards(list)`; состояние ошибки
   загрузки (сообщение + кнопка «Повторить» = перезагрузка данных).
4. **Локальная проверка:** `npx --yes serve .` → открыть в браузере; сценарии:
   все карточки на месте; 375px — 1 колонка; 768px — 2–3; 1280px — 4+; клик по
   карточке открывает рецепт в новой вкладке.

## Acceptance criteria (шаг считается готовым, когда)
- Страница рендерит все рецепты из JSON; адаптив проверен на 375/768/1280.
- Ошибки загрузки данных показываются пользователю, а не молчаливая пустая страница.
- Относительные пути; `node --check js/app.js` зелёный.
- Коммит `feat(ui): recipe cards with responsive grid [protocol-0001/02]`.
