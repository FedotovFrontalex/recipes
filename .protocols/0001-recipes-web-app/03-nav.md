# Шаг 03: Навигация и поиск

## Briefing
- **Цель:** фильтрация по категории + поиск по названию, пустые состояния, тёмная тема.
- **Ключевые файлы:**
  - `index.html` (изменить: секция фильтров — чипы категорий, поле поиска)
  - `js/app.js` (изменить: рендер чипов, фильтрация, debounce)
  - `css/styles.css` (изменить: чипы, sticky, тёмная тема, состояния)
- **Additional info:**
  - Чипы: «Все (N)» + каждая категория со счётчиком; рендерятся из данных, а не хардкодом.
  - На мобиле чипы — горизонтальная лента (`overflow-x: auto`, без переноса,
    скрытый скроллбар), липкая под шапкой (`position: sticky`).
  - Поиск: debounce 200 мс, регистронезависимо, по подстроке названия
    (`name.toLowerCase().includes(query)`), нормализация ё/е (`ё` → `е` обе стороны).
  - Фильтры комбинируются: категория AND поиск. Сброс поиска кнопкой ✕ в поле.
  - Пустой результат: «Ничего не найдено по запросу "..."» + кнопка «Сбросить фильтры».
  - Тёмная тема: только через `@media (prefers-color-scheme: dark)`, переопределение
    CSS-переменных — без дублирования стилей.
  - Доступность: у активного чипа `aria-pressed="true"`, счётчик результатов
    `aria-live="polite"` («Найдено: N»).

## Sub-tasks
1. **index.html:** `<section class="filters">` — контейнер чипов + `<input type="search">`.
2. **js/app.js:** `renderChips(categories)`, `applyFilters()` (категория + поиск),
   debounce, обработчики (click, input), empty state, сброс фильтров, счётчик «Найдено».
3. **css/styles.css:** стили чипов и активного состояния, sticky-лента, empty state,
   тёмная тема через переменные, hover/focus/active.
4. **Локальная проверка** (`npx --yes serve .`): категория + поиск вместе; сброс;
   пустой результат; ё/е («Пирог с яйцом» vs «яйцо»); тёмная тема в системной
   настройке; на 375px чипы скроллятся горизонтально.

## Acceptance criteria (шаг считается готовым, когда)
- Фильтры работают по отдельности и вместе; пустое состояние со сбросом.
- Тёмная тема применяется автоматически по системной настройке.
- `node --check js/app.js` зелёный.
- Коммит `feat(nav): category chips and search [protocol-0001/03]`.
