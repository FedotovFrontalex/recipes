### Шаг 01 — 2026-09-13
- **Сделано:** `package.json` (без зависимостей, `type: module`), `scripts/lib/csv.mjs`
  (RFC4180-парсер), `scripts/build-data.mjs` (CSV → `data/recipes.json`: `{total,
  categories, recipes}`; категории по первому появлению со счётчиками),
  `scripts/validate-data.mjs` (объём ≥ 280 и сверка с CSV, непустые поля, https-URL,
  без дублей ссылок, без кавычек-артефактов, категории сходятся с подсчётом).
  Итог: 290 рецептов, 11 категорий.
- **Почему так:** парсер вынесен в `lib/`, чтобы build и validate работали с одним и
  тем же разбором (SSOT для парсинга); `data/recipes.json` коммитится — сайт на Pages
  не выполняет сборку, данные готовы к отдаче статики. Проверка «7 названий с
  запятыми» — grep по «булгура, перца» ✓.
- **Проблемы и решения:** инструмент записи файлов дважды спотыкался о свежесозданные
  папки (`.protocols/…`, `scripts/lib/`) — помогло повторение записи после создания
  каталога; на результаты шага не повлияло.
- **Commit:** feat(data): generate recipes.json from csv [protocol-0001/01]

### Шаг 02 — 2026-09-13
- **Сделано:** `index.html` (семантический каркас, `lang=ru`, noscript),
  `css/styles.css` (дизайн-токены в переменных, сетка `auto-fill minmax(230px,1fr)`,
  карточка целиком-ссылка, hover-lift, `:focus-visible`, тач-таргеты ≥ 44px),
  `js/app.js` (fetch по относительному пути, рендер карточек, экран ошибки с
  «Повторить»). Новый `scripts/dev-check.mjs`: поднимает одноразовый http-сервер и
  автоматически проверяет отдачу и содержимое страницы/CSS/JS/JSON (10 проверок).
- **Почему так:** сетка на `auto-fill` вместо медиазапросов — 1 колонка на телефоне
  и 4–5 на десктопе получаются сами, меньше точек поломки. Автопроверка добавлена,
  потому что браузерной сессии у агента нет: дев-сервер + fetch заменяют ручную
  проверку и остаются в gates на следующие шаги.
- **Проблемы и решения:** записи файлов в ещё не созданные папки (`css/`, `js/`)
  падают — папки создавать до записи (тот же урок, что с `scripts/lib/`).
- **Commit:** feat(ui): recipe cards with responsive grid [protocol-0001/02]

### Шаг 03 — 2026-09-13
- **Сделано:** поиск (`input#search` + кнопка ✕), чипы категорий («Все (290)» + 11
  категорий со счётчиками, `aria-pressed`), комбинированная фильтрация (категория AND
  поиск), debounce 200 мс, нормализация ё/е, пустое состояние с кнопкой «Сбросить
  фильтры», счётчик «Найдено: N». Стили: липкая панель фильтров, горизонтальная
  лента чипов на мобиле (скрытый скроллбар), тёмная тема через переопределение
  переменных `prefers-color-scheme`. dev-check расширен до 13 проверок — все зелёные.
- **Почему так:** фильтры в одном `filteredRecipes()` (единый источник правды
  состояния); чипы строятся из данных, а не хардкодом — новые категории из CSV
  подхватятся сами. Тёмная тема — только переменные, без дублей стилей.
- **Проблемы и решения:** вручную сценарии в браузере агент выполнить не может —
  статические проверки вынесены в dev-check; визуальную приёмку делает пользователь
  на шаге 4 после включения Pages (или локально через `npx --yes serve .`).
- **Commit:** feat(nav): category chips and search [protocol-0001/03]
