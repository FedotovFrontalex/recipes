# .protocols/ — протоколы доработок

Протокол — единица работы во FlowForge. Папка `NNNN-<краткое-имя>/` создаётся командой
`/flow-new` (полный, в worktree) или `/flow-mini` (быстрый, на main).

## Соглашения

- **NNNN** — порядковый номер протокола (идентификатор); имя папки — для людей.
- Команды работают по номеру: «прочитай протокол 0042 из .protocols/».
- Внутри: `plan.md` (ADR + контракт), `YY-<имя>.md` (шаги), `log.md` (append-only журнал),
  `context.md` (текущее состояние), на ревью — `review-plan.md` и `review-log.md`.
- Протокол живёт в ветке и вливается в main вместе с кодом (merge протокола).
- После merge папка остаётся на main как история решений. Старые протоколы (>50 штук)
  можно переносить в `.protocols/archive/`.

## Номера

Номер берётся как max существующий в `.protocols/` + `../worktrees/` (и `archive/`) + 1.
Команды проверяют уникальность при создании.
